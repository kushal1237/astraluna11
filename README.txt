ASTRALUNA APK DOWNLOAD WEBSITE

Files:
- index.html: website page
- style.css: responsive styling
- script.js: small progressive enhancement
- downloads/Astraluna.apk: APK supplied for this site

Preview locally:
1. Extract this ZIP.
2. Open index.html in a browser. The real Moon image is loaded from NASA online, so an internet connection is needed to display it.

Publish with GitHub Pages:
1. Create a new GitHub repository.
2. Upload all files and folders from this package (keep the downloads folder).
3. Open repository Settings -> Pages.
4. Choose Deploy from a branch, select main and /(root), then Save.
5. Wait for GitHub Pages to publish the site.

Important:
- The APK is about 48 MB. Confirm your hosting provider's file-size limits before publishing.
- Android may show an unknown-source warning for APKs installed outside Google Play. Users should install only if they trust the source.
- The moon image is a real NASA/Lunar Reconnaissance Orbiter photograph loaded from NASA's website. The website needs internet access to show it.
